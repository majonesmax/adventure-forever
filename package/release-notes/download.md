## Download

| | |
|---|---|
| **macOS** (Apple Silicon: M1 and later) | `Adventure-Forever-macos-arm64.zip` (below) |
| **Windows** (64-bit) | `Adventure-Forever-windows-x64.zip` (below) |
| Linux, Intel Macs | [run it from source](https://github.com/majonesmax/adventure-forever#running-it-from-source-macos-windows-linux) |

Unzip, open **Adventure Forever**, and drag your own Adventure ROM onto the window the first time; it isn't included. The app isn't signed, so the first launch needs one extra step:
- **macOS:** double-click the app; when macOS refuses, open **System Settings → Privacy & Security**, click **Open Anyway** next to *"Adventure Forever" was blocked*, and confirm. (Or, in Terminal: `xattr -dr com.apple.quarantine "Adventure Forever.app"`.)
- **Windows:** **More info** → **Run anyway**.

Press **H** in the game for every key. More packs: **[Shall we play a game?](https://github.com/majonesmax/shall-we-play-a-game)**.
