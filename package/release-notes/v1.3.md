# VGA like VGA

The **VGA** look now plays by a real VGA card's rules. Before, it used one fixed set of colours with dithering,
closer to EGA or early Windows than to a VGA game. Now:

- **256 colours, picked for what's on screen:** each cast and world gets its own palette, chosen from its
  pictures - the card's 16 standard colours, two for menus and text, 64 for the characters and the rest for the
  rooms (including the dark rooms by torchlight).
- **64 levels a channel**, as the card had, and every screen is drawn in those 256 colours only. No dithering.

How true each look is to its machine: [docs/platform-rules.md](https://github.com/majonesmax/adventure-forever/blob/main/docs/platform-rules.md).

Also:

- **Fix:** a pack's song for the chiptune synth may leave out drums, style and loop. It used to crash without
  drums.
- **The code is easier to read**, with the same pictures and sound, and a check keeps it that way.
- **`--check`:** the app plays itself for a few seconds and says whether it works. Both downloads are now
  built and checked this way on GitHub.
- The app keeps running, silently, on a computer with no sound device.
